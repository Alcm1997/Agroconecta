📖 1. Narración del Proceso de Ingeniería

El proceso de Venta en Línea de AgroConecta inicia cuando un Cliente (productor agrícola o comprador) accede a la plataforma web y navega por el catálogo de productos (fertilizantes, esquejes, packs y frutas frescas).

Para realizar una compra, el cliente debe estar registrado e iniciar sesión. Si no tiene cuenta, el sistema lo redirige al formulario de registro. Una vez autenticado, el cliente agrega productos al carrito y procede al checkout.

En el checkout, el cliente confirma sus datos de entrega (dirección, departamento, distrito) y selecciona el método de pago: Yape, Plin o Tarjeta. Al confirmar, el sistema genera el pedido con estado "Pendiente" y permite al cliente imprimir o exportar su boleta en PDF.

El Administrador revisa los pedidos pendientes en el panel de control. Si aprueba el pedido, genera la Guía de Remisión donde designa el transportista registrado y su vehículo para realizar la entrega.

El Almacén prepara el despacho (picking) según la guía. El Transporte recoge los productos y realiza la entrega al cliente. Una vez entregado, el transportista notifica al Administrador para que cambie el estado del pedido de "Pendiente" a "Entregado".

Finalmente, el sistema actualiza el Dashboard de Reportes con las métricas de venta, cerrando el ciclo del proceso.

📋 2. Etapas Obligatorias del Proceso

1
IDENTIFICACIÓN - Navegación y Selección
Cliente navega el catálogo, visualiza productos y agrega al carrito.
2
AUTENTICACIÓN - Registro/Login Obligatorio
Cliente debe registrarse o iniciar sesión para continuar con la compra.
3
CHECKOUT - Pago y Confirmación
Cliente confirma datos, selecciona método de pago (Yape/Plin/Tarjeta), genera boleta PDF.
4
GESTIÓN - Revisión y Guía de Remisión
Administrador revisa pedido, lo aprueba y genera Guía de Remisión con transportista asignado.
5
LOGÍSTICA - Despacho y Entrega
Almacén prepara picking, Transporte recoge y entrega al cliente.
6
CIERRE - Confirmación y Reportes
Transporte notifica entrega, Admin cambia estado a "Entregado", Dashboard se actualiza.

📝 4. Ficha de Caracterización del Proceso

Nombre del Proceso Venta de Productos Agrícolas en Línea
Tipo de Proceso Proceso Misional (Core Business)
Objetivo Comercializar productos agrícolas conectando productores con compradores, eliminando intermediarios
Alcance Desde el ingreso del cliente a la tienda hasta la entrega del producto y actualización de reportes
Owner (Responsable) Área Comercial / Administrador del Sistema
Entradas Solicitud de compra del cliente, Datos de pago, Dirección de entrega
Salidas Pedido entregado, Boleta/Factura PDF, Guía de Remisión, Reporte de ventas actualizado
Proveedores Cliente (datos), Pasarela de pago (Yape/Plin/Tarjeta), Almacén (productos)
Clientes Productores agrícolas, Compradores mayoristas/minoristas
Recursos Plataforma web AgroConecta, Base de datos PostgreSQL, Flota de transporte, Personal administrativo
Documentos Generados 📄 Pedido, 📄 Boleta/Factura PDF, 📄 Guía de Remisión

📊 5. Indicadores de Gestión (KPIs)

> 5%
Tasa de Conversión
= (Pedidos / Visitas) × 100
< 72h
Tiempo Promedio de Entrega
= Σ(Fecha entrega - Fecha pedido) / N
< 10%
Tasa de Cancelación
= (Cancelados / Total) × 100
> 4.5
Satisfacción del Cliente
= Promedio encuestas (1-5)

🔄 6. Metodología PHVA Aplicada

P
PLANEAR

Diseño del modelo TO-BE, definición de KPIs, planificación de recursos y capacitación del equipo.

H
HACER

Implementación del sistema AgroConecta, ejecución del proceso de ventas en línea.

V
VERIFICAR

Medición de indicadores en Dashboard, análisis de datos de ventas, revisión de tiempos de entrega.

A
ACTUAR

Mejora continua, optimización de flujos, corrección de cuellos de botella, reingeniería si es necesario.
